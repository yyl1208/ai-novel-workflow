# 平台适配与市场调研方法

> 开书前或方向调整时参考。数据需现采，本文只给口径与方法。

## 一、数据口径（订阅数据各平台均不公开）

| 平台 | 可用公开指标 | 说明 |
|---|---|---|
| 起点 | 月票榜（含月票数） | 付费用户投票，最接近付费意愿风向标 |
| 纵横 | 月票榜 | 绝对值低于起点，只看相对位次 |
| 番茄 | 阅读榜「在读人数」 | 免费模式核心指标（留存） |
| 书旗 | 大神榜/好书榜 | 编辑推荐+口碑综合，无精确数值 |

采集方法：直接抓取各平台官网公开榜单页（起点 `/rank/yuepiao/`、纵横 `/rank/details.html`、番茄 `/rank/`、书旗首页），必要时用搜索补充。**无需爬虫脚本**，公开页已覆盖；报告须声明口径与局限。

## 二、平台差异对写法的直接影响

| 维度 | 付费端（起点/纵横） | 免费端（番茄） |
|---|---|---|
| 开篇耐心 | 较高，系统可第 2—3 章激活 | 低，系统建议第 1—2 章内出现 |
| 简介 | 一句话设定+反差 | 标签前置：【种田】【求生】【长生】 |
| 更新 | 稳定即可 | 日更 6000 字起，断更直接掉榜 |
| 钩子节点 | 可慢热，靠体系感 | 每 3 章要有一次资源/危机反馈 |

## 三、当前赛道信号（2026-09 采样，需复核）

- **"修真文明"≈种田式修仙**：起点月票榜头部有《玄鉴仙族》（宗族培育）、《没钱修什么仙？》。与本工作流产出天然同源，是最接近的热门赛道。
- **种田/日常流已进付费头部**：《1984：从破产川菜馆开始》（年代+美食+种田）进起点月票前十——但它是用"美食+烟火气"包装的，裸"种田"不容易出头。
- **求生+基建是免费端流量密码**：番茄游戏/体育榜几乎被求生文承包（幽灵船、房车、末世囤货）。
- **长生流升温**：纵横"一百岁还要修仙"、番茄"系统赋我长生"。建议前 50 章只留"寿命账本"钩子，大揭底放中期。
- **反差幽默标题成头部标配**：没钱修什么仙？/ 请勿高考时渡劫 / 让仙门再次伟大。
