# 模板文件说明与填写顺序

> assets/novel-project-templates/ 共 19 个文件的用途说明。新项目由 `scripts/init_novel_project.py` 复制。

## 目录与用途

| 文件 | 用途 | 谁维护 |
|---|---|---|
| `00-项目状态.md` | 仪表盘：当前章节、必读清单、待确认项、禁止恢复的旧设定、下一步入口 | 作者填基本信息，AI 每次回写 |
| `01-开书定位.md` | 七问：目标读者/主类型/核心情绪/初始困境/三个"为什么"（点开/读十章/读几十万字） | 作者 |
| `02-核心设定.md` | 七项：一句话故事/主线目标/失败代价/核心冲突/重复剧情发动机/终局方向/不可改设定 | 作者 |
| `写作规则.md` | 八条铁律 + 八步循环 + 冷读清单 + 回写清单 + S1/S2/S3 分级 | 模板，作者确认后生效 |
| `人物/主角.md`、`配角.md` | 九要素人物卡 | 作者 |
| `人物/人物关系.md` | 关系矩阵 + 关系变化记录 | 作者建，AI 回写变化 |
| `大纲/全书大纲.md` | 终局目标/对立力量/阶段升级/不可逆节点 | 作者（可 AI 起草草案） |
| `大纲/分卷大纲.md` | 每卷：主动目标/对立利益/高潮/卷后新局面 | 作者 |
| `大纲/滚动细纲-001-010章.md` | 只细化未来 5—12 章 | 作者定，AI 起草 |
| `追踪/时间线.md` | 绝对日期、时刻、事件顺序 | AI 回写 |
| `追踪/角色状态.md` | 位置/身体/情绪/目标/**已知信息**（防上帝视角） | AI 回写 |
| `追踪/伏笔.md` | 新增/推进/回收/最后出现章节 | AI 回写 |
| `追踪/资源与权限.md` | 钱/物/身份/能力/权限台账 | AI 回写 |
| `审核与复盘/章节合同-模板.md` | 十问合同 + 冷读结果 + 裁决栏 | 复制后按章填 |
| `正文/README.md` | 命名规则 `第NNN章-标题.md`，只有裁决通过的稿才能进 | 说明 |
| `待确认/README.md` | 初稿/修改中/试验稿存放，转正后删除 | 说明 |
| `审核与复盘/README.md` | 合同、冷读报告、复盘存放规则 | 说明 |

## 九要素人物卡

公开目标、当前利益、私下欲望、害怕失去、底线与缺陷、资源与权限、利益冲突、语言指纹、重大刺激反应。
建议追加"已知信息边界"（他知道/不知道/误以为）——这是防"上帝视角泄密"的最有效字段。

## 作者填写顺序

01 定位七问 → 02 核心设定七项 → 主角九要素 → 全书大纲 → 分卷大纲（卷一）→ 滚动细纲（至少 001—003 章）

## 资料自洽检查清单（作者填完后 AI 执行）

- 一句话故事 vs 核心冲突：是否咬合？
- 主角私下欲望 vs 初始困境：能否驱动行动？
- 重复剧情发动机 vs 预计篇幅：能否支撑长线不崩？
- 全书大纲终局 vs 02 终局方向：一致？
- 分卷大纲卷一 vs 全书大纲第一阶段：对齐？
- 第一章细纲 vs 01 定位的"读者为什么点开"：兑现了没有？
