# 01-开书定位

> 本文件回答「这本书是写给谁的、靠什么留住读者」。写正文之前必须填写完整，写作过程中不得随意更改；确需调整时，须作者明确确认并记入 00-项目状态.md。

## 定位七问

| 字段 | 填写内容 |
|---|---|
| 目标读者 | （填写：谁在读？年龄段、阅读偏好、常出没的平台） |
| 主类型 | （填写：如都市脑洞、玄幻、悬疑、历史、科幻等，主类型只能有一个） |
| 核心情绪 | （填写：读者读完最强烈的情绪是什么？爽感、紧张、好奇、治愈……） |
| 主角初始困境 | （填写：开篇时主角陷在什么具体麻烦里？越具体越好） |
| 读者为什么点开 | （填写：书名 +简介 + 第一章前 500 字承诺了什么？） |
| 为什么读十章 | （填写：前十章靠什么钩子让读者留下来？） |
| 为什么能读几十万字 | （填写：支撑长线的重复剧情发动机是什么？为什么不会写崩？） |

## 填写说明

- 每一项都要写出**具体答案**，不能停留在「热血」「好看」这类抽象词。
- 「读者为什么点开 / 为什么读十章 / 为什么能读几十万字」三问必须能分开回答——它们分别对应点击、留存、长线。
- 填写完成后，请到 `00-项目状态.md` 把「下一步入口」更新为「开写全书大纲」。
