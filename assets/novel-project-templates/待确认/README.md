# 待确认目录说明

## 用途

存放**尚未成为正式事实**的稿件，包括：

- 冷读发现 S1/S2 未清零、仍在修改中的章节
- 已完成初稿但等待作者裁决（DECIDE）的章节
- 被作者退回修改的章节
- 试验性段落、备选写法

## 事实唯一原则

- `正文/` 与 `待确认/` **不能并列两个「最新版」**。
- 待确认稿在通过作者裁决并转入 `正文/` 之前，不作为事实依据——写新章、回写数据库时都不得引用。
- 稿件转正后，从本目录删除对应文件（转正即删除，避免双份并存）。

## 命名规则

```
第001章-章节标题-待确认.md
第002章-章节标题-v2-待确认.md
```

## 流转

```
DRAFT/REVISE → 待确认/ → 作者裁决(DECIDE) → 正文/（转正后从本目录移除）
```
