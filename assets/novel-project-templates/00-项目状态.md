# 00-项目状态

> 本文件是整个项目的「仪表盘」。每完成一章、每次确认、每次方向调整，都必须回写到这里。
> Agent 每次开工前，必须先读本文件，以本文件记录的事实为准。

## 基本信息

| 字段 | 内容 |
|---|---|
| 项目名称 | （填写：书名或暂定名） |
| 搭建日期 | 2026-08-23 |
| 当前阶段 | 模板搭建完成，等待作者填写定位、设定与人物资料 |

## 状态总览

| 字段 | 当前值 | 说明 |
|---|---|---|
| 正式正文路径 | （暂无） | `正文/` 目录下的正式章节文件 |
| 当前章节 | 第 000 章（未开始） | 最新已确认的正式章节 |
| 最近一次确认 | （暂无） | 最近一次由作者裁决通过的章节与日期 |
| 本次必读 | 01-开书定位.md、02-核心设定.md | 下一次写作前必须先读的文件 |
| 待确认稿 | 无 | `待确认/` 目录中的稿件，未通过前不算正式事实 |
| 禁止恢复的旧设定 | 无 | 已被作者否决、不得在任何后续章节中复活的设定 |
| 下一步入口 | 等待作者填写 01、02、人物、大纲 | 当前最优先要做的事 |

## 使用规则

1. **事实唯一**：正式正文只有一套，存放在 `正文/`；`待确认/` 中的稿件在通过作者确认之前，不作为事实依据。
2. **先读后写**：每次写作前必须先读「本次必读」列出的文件。
3. **禁止恢复**：列入「禁止恢复的旧设定」的内容，任何章节不得再使用。
4. 每完成一章并回写数据库后，同步更新本文件。
