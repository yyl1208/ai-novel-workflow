# 02-核心设定

> 本文件是全书的「宪法」。正式正文一旦写出的内容与本文件冲突，以正文为准并在此登记变更；正文未覆盖的设定，Agent 不得擅自补全。

## 核心七项

| 字段 | 填写内容 |
|---|---|
| 一句话故事 | （填写：用一句话讲清主角 + 主线目标 + 最大阻力） |
| 主线目标 | （填写：主角从头到尾在追求的那个具体结果） |
| 失败代价 | （填写：主线失败会失去什么？必须让读者在乎） |
| 核心冲突 | （填写：谁/什么力量在阻止主角？为什么无法调和？） |
| 重复剧情发动机 | （填写：能反复产生新剧情又不写崩的机制，如升级体系、案件来源、势力博弈等） |
| 终局方向 | （填写：故事最终走向哪里？结局的大方向） |
| 不能随便改变的设定 | （填写：世界观、力量体系、关键背景等硬约束清单） |
