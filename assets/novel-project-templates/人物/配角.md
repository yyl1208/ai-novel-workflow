# 配角人物卡

> 每个重要配角复制一份下方结构。只有一两个配角的，直接在下方填写即可；配角多时建议每人一个文件，命名为 `配角-姓名.md`。

## 配角一

### 基础信息
| 字段 | 内容 |
|---|---|
| 姓名 | （填写） |
| 身份 | （填写） |
| 与主角的关系 | （填写） |
| 出场章节范围 | （填写） |

### 九要素人物卡

| 要素 | 追问 | 填写 |
|---|---|---|
| 公开目标 | 别人以为他想要什么？ | （填写） |
| 当前利益 | 这件事与他有什么关系？ | （填写） |
| 私下欲望 | 他真正想得到什么？ | （填写） |
| 害怕失去 | 什么会逼他行动？ | （填写） |
| 底线与缺陷 | 他绝不会做什么？哪里会犯错？ | （填写） |
| 资源与权限 | 他能调动什么？有权决定什么？ | （填写） |
| 利益冲突 | 他为什么会阻止或帮助主角？ | （填写） |
| 语言指纹 | 词汇、节奏和回避方式是什么？ | （填写） |
| 重大刺激反应 | 遇到背叛、失去、机会或公开羞辱时，先做什么、隐藏什么、之后改变什么？ | （填写） |
