## 细纲条目格式

每章一条，包含：

| 字段 | 说明 |
|---|---|
| 章节号 | 第 00N 章 |
| 本章目标 | 主角这一章主动要完成什么 |
| 阻力 | 谁在阻止，为什么 |
| 主场面 | 最值得看的具体场面 |
| 章尾新局面 | 不可逆的变化 |
| 涉及人物 | 出场人物清单 |
| 涉及伏笔 | 新增/推进/回收的伏笔编号 |
| 状态 | 待写 / 初稿 / 待确认 / 已完成 |
