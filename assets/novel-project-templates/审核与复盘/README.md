# 审核与复盘目录说明

## 存放内容

1. **章节合同**：每章一份，从 `章节合同-模板.md` 复制，命名为 `章节合同-第NNN章.md`。
2. **冷读报告**：每章冷读的详细记录（查了什么、发现什么问题、如何清零），命名 `冷读-第NNN章.md`。
3. **滚动复盘**：每写完 5—10 章做一次，命名 `复盘-第NNN-NNN章.md`。

## 滚动复盘模板（三问）

每 5—10 章回答一次：

### 1. 保留什么？
> 哪些写法、节奏、场景类型是有效的？下一阶段继续用。

### 2. 停止什么？
> 哪些手法已经失效或读者会腻？立刻停。

### 3. 下一阶段试验什么？
> 选 1—2 个新东西小范围试，不贪多。

复盘结论如果影响方向，须同步更新 `01-开书定位.md` 或 `02-核心设定.md` 并登记变更。
